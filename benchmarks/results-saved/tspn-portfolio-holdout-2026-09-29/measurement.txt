Commands used the public benchmark CLI, existing frozen executables, and the already selected holdout inputs. Each invocation used one repetition, a 1-second solver budget, and an 8-second per-process timeout. The four modes ran sequentially in this order:

```sh
python3 benchmarks/tpp.py tspn-benchmark --skip-build --ours-binary /private/tmp/tpp-tspn-unordered-portfolio-2026-09-29 --fekete-binary /private/tmp/tpp-tspn-baseline-b70cda3/tpp-fekete-cycle --fekete-source third_party/tspn-socg --build-dir /private/tmp/tpp-tspn-comparison-build --inputs holdout-inputs.json --output default --seconds 1 --external-timeout 8 --repetitions 1
# Repeat with output dfs-bfs and: --search-strategy dfs-bfs
# Repeat with output portfolio-no-sharing and: --portfolio-no-sharing
# Repeat with output portfolio and: --portfolio
```

Each mode directory contains its own exact resolved paths, settings, binary hashes, selected input copy, raw rows, summary, strata and analysis. `source.patch` and `source-files.sha256` snapshot the workspace source before timing; the native executable hash is in `frozen-binary.sha256`.

The same six-case holdout was rerun with `--repetitions 3`; its four outputs are under `repeat3/{default,dfs-bfs,race,cooperative}`. The same frozen binaries and limits were used. The benchmark runner config preserves the legacy `threads` alias for `ours_threads`, and records `fekete_threads: 1`.

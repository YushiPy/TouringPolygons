# Figuras compartilhadas dos relatórios

As 19 imagens desta pasta eram cópias idênticas em `relatorio/` e
`relatorio-parcial/`. Ambos os documentos as encontram por `\graphicspath`;
compile cada fonte a partir da sua própria pasta.

Os gráficos de desempenho que diferem entre os relatórios continuam nas
pastas originais, mesmo quando têm o mesmo nome. As figuras e os resultados
são registros históricos, não medições do solver atual.

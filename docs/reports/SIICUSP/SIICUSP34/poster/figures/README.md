# Figuras do pôster

- `usp-route-print.png` é gerado por `../render_usp_route.py` a partir de
  `apps/siicusp34/data/usp-preview.svg`. O SVG do app fornece os 51 contornos,
  a rota e o gradiente de ordem de visita. A imagem tem 6300 × 3600 pixels,
  aproximadamente 305 dpi na largura usada no A0.
- `fapesp-logo.svg` é a [variante preta da marca FAPESP publicada no Wikimedia
  Commons](https://commons.wikimedia.org/wiki/File:Logo_fapesp_em_preto.svg),
  atribuída à FAPESP. `fapesp-logo.png` é a conversão para inclusão no PDF.
  O autor confirmou autorização para utilizar a marca neste pôster.

Nenhuma das três imagens genéricas `image.png`, `image2.png` ou `image3.png`
foi usada.

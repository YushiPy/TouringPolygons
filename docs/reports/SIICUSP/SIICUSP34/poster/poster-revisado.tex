No entanto, para o TPP com polígonos convexos e ordem fixa, Dror et al. (2003) descrevem um algoritmo em $O(nk^2 \log n)$, depois melhorado por Tan \& Jiang (2017) para $O(nk^2)$.   \block{competition-story}{42.7}{25.34}{38.4}{\tagtext Duas abordagens\par\vspace{0.20cm}\bodytext Enumerar ordens e peças convexas com branch and bound é uma estratégia natural para o TPP de ordem livre.

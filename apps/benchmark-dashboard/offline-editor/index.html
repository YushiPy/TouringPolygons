Edit a fixed-order TPP instance locally. Nothing is sent to the dashboard.

Layers

Local instances

Click Draw and add at least three points to create a polygon. In Move mode, drag endpoints, vertices, or a whole polygon. Use Shift-drag or Select to select vertices.

The fixed-order solver runs locally through the optional WebAssembly build. Editing and JSON export work even when the WASM files are unavailable.
